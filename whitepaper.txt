​2. Dynamic Mining Mechanics & Supply Control
​To make the 500M $BKT mining pool last through heavy traffic without inflating prematurely, we implement a Traffic-Adaptive Halving Algorithm.
​Base Streak Loop (7-Day Cycle):
​Days 1–6 build sequential multiplier bonuses.
​Day 7 awards a peak Streak Bonus.
​On Day 8, the cycle resets automatically to Day 1 to create an active daily habit loop without infinite multiplier compounding.
​Dynamic Reward Scaling (Halving Tiers):
​As active user volume scales, base task and daily check-in rewards dynamically decrease based on active global user thresholds.
​Phase 1 (< 50,000 Active Users): 100% Base Yield.
​Phase 2 (50,000 – 250,000 Users): 50% Base Yield (1st Halving).
​Phase 3 (250,000 – 1,000,000 Users): 25% Base Yield (2nd Halving).
​Phase 4 (1,000,000+ Users): 12.5% Base Yield (3rd Halving).
​Referral Guardrails:
​Default cap: 10 Referrals per user (prevents bot farms from draining the allocation).
​Administrative Override: Custom higher referral caps can be manually granted to high-volume creators/promoters directly via Firestore.
